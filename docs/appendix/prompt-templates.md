## 1. 새 기능 만들기

### 페이지 만들기

```
[페이지명] 페이지를 만들어줘.
(app/[경로]/page.tsx)

표시할 내용:
- [내용1]
- [내용2]
- [내용3]

기능:
- [기능1]
- [기능2]

'use client' 사용
TypeScript + Tailwind CSS
모바일 반응형
```

**예시:**
```
로그인 페이지를 만들어줘.
(app/login/page.tsx)

표시할 내용:
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 링크

기능:
- Supabase Auth로 로그인
- 성공하면 메인 페이지로 이동
- 에러 시 메시지 표시

'use client' 사용
TypeScript + Tailwind CSS
모바일 반응형
```

### 컴포넌트 만들기

```
[컴포넌트명] 컴포넌트를 만들어줘.
(app/components/[컴포넌트명].tsx)

Props:
- [prop1]: [타입]
- [prop2]: [타입]

표시할 내용:
- [내용1]
- [내용2]

스타일:
- [스타일1]
- [스타일2]

TypeScript + Tailwind CSS
```

**예시:**
```
ProductCard 컴포넌트를 만들어줘.
(app/components/ProductCard.tsx)

Props:
- id: number
- title: string
- price: number
- imageUrl: string | null

표시할 내용:
- 상품 이미지
- 제목
- 가격 (₩, 콤마 표시)

스타일:
- 카드 형태
- 그림자 효과
- 호버 시 살짝 올라감

TypeScript + Tailwind CSS
```

```

필드:
- [필드1]: [타입], [설명]
- [필드2]: [타입], [설명]

관계:
- [다른 테이블과의 관계]

RLS 정책:
- [정책1]
- [정책2]
```

**예시:**
```
comments 테이블을 만드는 SQL을 작성해줘.

필드:
- id: bigint, 자동 증가
- content: text, 댓글 내용
- product_id: bigint, 상품 참조
- user_id: uuid, 사용자 참조
- created_at: timestamp, 자동 생성

관계:
- products 테이블과 1:N
- profiles 테이블과 N:1

RLS 정책:
- 누구나 조회 가능
- 로그인 사용자만 작성 가능
- 본인만 삭제 가능
```

## 8. 프롬프트 작성 팁

### 좋은 프롬프트의 특징

1. **구체적** - 원하는 것을 명확하게
2. **맥락 제공** - 현재 상황 설명
3. **예시 포함** - 원하는 결과 예시
4. **제약 조건** - 기술 스택, 조건 명시

### 피해야 할 것

```
❌ 나쁜 예:
"로그인 만들어"
"에러 고쳐"
"이상해"

✅ 좋은 예:
"Supabase Auth를 사용해서 이메일 로그인 페이지를 만들어줘..."
"이 에러가 나는데 해결해줘: [에러 메시지]"
"버튼을 클릭해도 아무 반응이 없어. 콘솔에 이런 에러가 나: [에러]"
```
