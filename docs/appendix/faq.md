# 자주 묻는 질문 (FAQ)

강의 중 자주 나오는 질문들을 모았습니다.

---

## 설치 관련

### Q: Node.js 버전이 맞는지 어떻게 확인하나요?

터미널에서:
```bash
node --version
```

`v18` 이상이면 됩니다. (예: v18.17.0, v20.10.0)

### Q: npm 명령어가 안 돼요

**Windows:**
1. Node.js를 재설치해보세요
2. 설치 시 "Add to PATH" 옵션 체크 확인
3. 터미널을 새로 열어보세요

**Mac:**
```bash
# Homebrew로 재설치
brew install node
```

### Q: Cursor가 안 열려요

1. 재설치해보세요
2. 관리자 권한으로 실행해보세요 (Windows)
3. 보안 설정 확인 (Mac)

## AI 사용 관련

### Q: AI 응답이 영어로 나와요

프롬프트에 "한국어로 대답해줘" 또는 "Korean"을 추가하세요.

```
가계부 앱을 만들어줘. 한국어로 설명해줘.
```

### Q: AI가 엉뚱한 대답을 해요

1. **더 구체적으로** 요청해보세요
2. **현재 상황**을 설명해주세요
3. **새 채팅**에서 다시 시작해보세요

### Q: Apply 버튼이 안 보여요

1. 코드 블록 위에 마우스를 올려보세요
2. 커서 버전을 업데이트해보세요
3. 채팅 창을 닫았다 다시 열어보세요

### Q: AI가 계속 에러를 만들어요

에러 메시지를 포함해서 다시 요청:
```
이 에러가 나는데 해결해줘:
[에러 메시지 전체 복사]

현재 코드:
[해당 파일 코드]
```

## 개발 서버 관련

### Q: localhost:3000이 안 열려요

1. `npm run dev`가 실행 중인지 확인
2. 터미널에 에러가 없는지 확인
3. 다른 프로그램이 3000 포트를 쓰고 있는지 확인:
   ```bash
   # 다른 포트로 실행
   npm run dev -- -p 3001
   ```

### Q: 개발 서버를 어떻게 끄나요?

터미널에서 `Ctrl + C`

### Q: 저장해도 변경사항이 안 보여요

1. 브라우저 새로고침 (F5)
2. 강력 새로고침 (Ctrl + Shift + R)
3. 터미널 에러 확인
4. 서버 재시작 (`Ctrl + C` 후 `npm run dev`)

## Supabase 관련

### Q: 데이터가 저장이 안 돼요

1. `.env.local` 파일 확인
   - URL과 KEY가 제대로 들어갔나요?
   - 따옴표 없이 넣었나요?
2. 서버 재시작했나요? (환경변수 변경 후 필수)
3. RLS 정책이 설정되어 있나요?

### Q: RLS 정책이 뭔가요?

Row Level Security의 약자입니다.
행 단위로 접근을 제어하는 보안 기능입니다.

예: "본인 데이터만 수정 가능" 같은 규칙

### Q: Supabase 무료 제한이 뭔가요?

- 프로젝트 2개
- 500MB 데이터베이스
- 1GB 파일 저장
- 7일 이상 미사용 시 일시정지 (다시 활성화 가능)

### Q: 프로젝트가 일시정지됐어요

Supabase 대시보드에서 해당 프로젝트를 클릭하면
"Restore project" 버튼이 있습니다.

## GitHub 관련

### Q: push가 안 돼요

1. GitHub 로그인 확인
2. 저장소 권한 확인
3. 인터넷 연결 확인

```bash
# 원격 저장소 확인
git remote -v
```

### Q: 커밋이 안 돼요

변경사항이 있는지 확인:
```bash
git status
```

파일이 스테이징 되었는지 확인:
```bash
git add .
```

### Q: GitHub 계정 연결은 어떻게 하나요?

커서에서:
1. `View` → `Command Palette`
2. "GitHub: Sign in" 검색
3. 브라우저에서 인증

## 배포 관련

### Q: Vercel 배포가 실패해요

1. **Logs** 탭에서 에러 메시지 확인
2. 환경변수 설정 확인
3. 빌드 명령어 확인 (보통 자동 감지됨)

### Q: 배포는 됐는데 사이트가 안 돼요

1. 환경변수가 제대로 설정됐나요?
2. Supabase RLS 정책이 설정됐나요?
3. 브라우저 콘솔(F12)에서 에러 확인

### Q: 배포 후 수정하려면?

코드 수정 → 커밋 → Push
Vercel이 자동으로 다시 배포합니다!

## 기타

### Q: TypeScript 에러가 많이 나요

AI에게 요청:
```
타입스크립트 에러가 많이 나.
타입을 제대로 정의해줘.
```

### Q: Tailwind CSS가 적용 안 돼요

1. `tailwind.config.js` 확인
2. `globals.css`에 Tailwind 지시어 확인:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;
   ```

### Q: 코드를 이해하고 싶어요

AI에게 질문:
```
이 코드가 뭘 하는 건지 쉽게 설명해줘:
[코드 붙여넣기]
```

### Q: 강의 끝나고 더 공부하려면?

1. 직접 프로젝트를 만들어보세요
2. 공식 문서를 읽어보세요
3. YouTube 튜토리얼을 찾아보세요
4. 다른 사람 코드를 읽어보세요 (GitHub)

## 문제가 해결 안 되면?

1. **에러 메시지 전체**를 복사
2. **현재 상황**을 정리
3. **AI에게 질문**

```
[상황 설명]

이런 에러가 나:
[에러 메시지]

어떻게 해결해?
```

그래도 안 되면 강사에게 질문하세요!
