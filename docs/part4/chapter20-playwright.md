# Chapter 20. E2E 테스트 자동화

기능을 추가할 때마다 "이전에 되던 게 안 되네요?" 경험 있으시죠?
**Playwright MCP**로 AI가 직접 브라우저를 조작하며 테스트합니다!

---

## 20.1 왜 테스트가 필요한가?

### 흔한 상황

```
Day 1: 로그인 기능 완성! ✅
Day 2: 상품 등록 기능 추가 ✅
Day 3: 검색 기능 추가 ✅
Day 4: 어? 로그인이 안 되네? 😱
```

### 수동 테스트의 한계

매번 이걸 다 확인해야 하나요?

```
□ 메인 페이지 로딩 확인
□ 회원가입 테스트
□ 로그인 테스트
□ 상품 목록 확인
□ 상품 등록 테스트
□ 상품 수정 테스트
□ 상품 삭제 테스트
□ 댓글 작성 테스트
□ 검색 기능 테스트
□ ...
```

시간도 오래 걸리고, 빠뜨리기도 쉽습니다.

### E2E 테스트란?

**End-to-End 테스트** = 사용자 입장에서 전체 흐름 테스트

```
실제 브라우저 열기
  ↓
버튼 클릭
  ↓
입력 폼 작성
  ↓
결과 확인
  ↓
성공/실패 판단
```

### Playwright MCP로 해결!

AI에게 말로 시키면 됩니다:

```
"로그인 기능 테스트해줘"
"상품 등록이 제대로 되는지 확인해줘"
"메인 페이지 로딩 테스트해줘"
```

## 20.2 Playwright MCP 연결하기

### Step 1: MCP 설정 추가

`.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    },
    "supabase": {
      "command": "npx",
      "args": [
        "-y",
        "@supabase/mcp-server-supabase@latest",
        "--access-token",
        "sbp_xxxxx"
      ]
    },
    "playwright": {
      "command": "npx",
      "args": ["-y", "@anthropic/playwright-mcp"]
    }
  }
}
```

### Step 2: Cursor 재시작

설정 후 Cursor를 완전히 종료했다가 다시 시작하세요.

### Step 3: 연결 확인

```
MCP Servers
├── context7 ✅
├── supabase ✅
└── playwright ✅  ← 새로 추가됨!
```

## 20.3 기본 테스트 작성하기

### 테스트 1: 메인 페이지 로딩

**AI에게 요청:**

```
localhost:3000 메인 페이지가 제대로 열리는지 테스트해줘.
"고구마마켓" 텍스트가 있는지 확인해줘.
```

**AI가 실행:**

```
AI: Playwright로 테스트를 시작합니다.

1. localhost:3000 접속 중...
2. 페이지 로딩 완료 ✅
3. "고구마마켓" 텍스트 검색 중...
4. 텍스트 발견! ✅

테스트 결과: 성공 ✅
- 페이지 로딩 시간: 1.2초
- 필수 요소 확인 완료
```

### 테스트 2: 상품 목록 확인

**AI에게 요청:**

```
메인 페이지에서 상품 카드가 표시되는지 확인해줘.
상품 카드에 제목, 가격이 있어야 해.
```

**AI가 실행:**

```
AI: 상품 목록을 확인합니다.

1. 메인 페이지 접속 ✅
2. 상품 카드 검색 중...
3. 발견된 상품 카드: 6개 ✅
4. 각 카드 요소 확인:
   - 제목 있음 ✅
   - 가격 있음 ✅
   - 이미지 있음 ✅

테스트 결과: 성공 ✅
```

### 테스트 3: 상품 상세 페이지

**AI에게 요청:**

```
첫 번째 상품 카드를 클릭해서
상세 페이지로 이동하는지 확인해줘.
상세 페이지에 설명, 판매자 정보가 있어야 해.
```

**AI가 실행:**

```
AI: 상품 상세 페이지를 테스트합니다.

1. 메인 페이지 접속 ✅
2. 첫 번째 상품 카드 클릭 ✅
3. URL 변경 확인: /products/15 ✅
4. 상세 페이지 요소 확인:
   - 상품명 ✅
   - 가격 ✅
   - 설명 ✅
   - 판매자 정보 ✅
   - 댓글 섹션 ✅

테스트 결과: 성공 ✅
```

## 20.4 핵심 사용자 흐름 테스트

### 로그인 흐름 테스트

**AI에게 요청:**

```
로그인 흐름을 테스트해줘:
1. 로그인 페이지로 이동
2. 이메일: test@test.com
3. 비밀번호: test1234
4. 로그인 버튼 클릭
5. 헤더에 닉네임이 표시되는지 확인
```

**AI가 실행:**

```
AI: 로그인 흐름을 테스트합니다.

1. /login 페이지 접속 ✅
2. 이메일 입력: test@test.com ✅
3. 비밀번호 입력: ******** ✅
4. 로그인 버튼 클릭 ✅
5. 페이지 이동 대기...
6. 메인 페이지로 리다이렉트 ✅
7. 헤더 확인 중...
8. "테스트유저" 닉네임 발견 ✅

테스트 결과: 성공 ✅
소요 시간: 2.3초
```

### 상품 등록 흐름 테스트

**AI에게 요청:**

```
상품 등록 흐름을 테스트해줘:
1. 먼저 로그인 (test@test.com / test1234)
2. 상품 등록 페이지로 이동
3. 제목: "테스트 상품 123"
4. 가격: 50000
5. 설명: "테스트 설명입니다"
6. 등록 버튼 클릭
7. 등록된 상품 페이지로 이동하는지 확인
```

**AI가 실행:**

```
AI: 상품 등록 흐름을 테스트합니다.

1. 로그인 진행... ✅
2. /products/new 페이지 접속 ✅
3. 폼 작성 중...
   - 제목 입력 ✅
   - 가격 입력 ✅
   - 설명 입력 ✅
4. 등록 버튼 클릭 ✅
5. 페이지 이동 대기...
6. /products/42 로 이동 ✅
7. 등록된 상품 확인:
   - 제목: "테스트 상품 123" ✅
   - 가격: 50,000원 ✅

테스트 결과: 성공 ✅
```

**AI에게 요청:**

```

```

**AI가 실행:**

```
AI: 스크린샷을 포함해서 테스트합니다.

**AI에게 요청:**

```
로그인 테스트해줘.

```

에러 발생 시:

```
AI: 테스트 중 에러가 발생했습니다.

1. /login 페이지 접속 ✅
2. 폼 작성 ✅
3. 로그인 버튼 클릭 ✅
4. ❌ 에러 발생!
   "Invalid login credentials"

스크린샷 저장: error-screenshot.png

## 20.7 테스트 실패 시 대응

### 실패 원인 파악

테스트가 실패하면:

```
AI: 상품 등록 테스트가 실패했습니다.

실패 지점: 등록 버튼 클릭 후
예상: /products/[id] 페이지로 이동
실제: /products/new 페이지 그대로

스크린샷: test-failed.png

가능한 원인:
1. 폼 유효성 검사 실패
2. 서버 에러 발생
3. DB 저장 실패

확인해볼 것:
- 브라우저 콘솔 에러
- 네트워크 요청 상태
- Supabase 로그
```

### MCP 조합으로 디버깅

```
테스트 실패했어.
Supabase MCP로 products 테이블에 방금 데이터가 저장됐는지 확인해줘.
```

```
AI: Supabase를 확인합니다.

products 테이블 최근 데이터:
- 마지막 INSERT: 5분 전

⚠️ 방금 등록한 데이터가 없습니다.

문제: INSERT 자체가 실행되지 않은 것 같습니다.
RLS 정책이나 user_id 문제일 수 있습니다.
```

## 20.8 Playwright 활용 팁

### 개발 서버가 켜져 있어야 해요!

```bash
npm run dev
```

테스트 전에 개발 서버가 실행 중인지 확인하세요.

### 테스트용 계정 준비

실제 데이터를 건드리지 않도록 테스트용 계정을 만들어두세요:

```
이메일: test@test.com
비밀번호: test1234
닉네임: 테스트유저
```

### 천천히 실행하기

너무 빨라서 뭐가 일어나는지 모르겠다면:

```
로그인 테스트해줘.
각 단계마다 1초씩 대기하면서 천천히 해줘.
```

### 특정 요소 기다리기

페이지 로딩이 느릴 때:

```
상품 목록이 로딩될 때까지 기다렸다가 테스트해줘.
최대 10초까지 기다려줘.
```
