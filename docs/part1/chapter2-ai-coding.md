# Chapter 2. AI로 코딩하는 법

이 챕터는 매우 중요합니다! 🌟

AI에게 어떻게 요청하느냐에 따라 결과물의 품질이 완전히 달라집니다.
이 내용을 잘 익혀두면 앞으로 모든 작업이 수월해집니다.

---

## 2.1 AI에게 잘 요청하는 법

### 프롬프트가 뭔가요?

> **프롬프트 = AI에게 보내는 요청/명령**
>
> "버튼 만들어줘"도 프롬프트고,
> "파란색 로그인 버튼을 만들어줘"도 프롬프트입니다.
>
> 어떻게 요청하느냐가 결과를 결정합니다!

### 나쁜 프롬프트 vs 좋은 프롬프트

**❌ 나쁜 예시:**
```
가계부
```

**✅ 좋은 예시:**
```
가계부 앱을 만들어줘.

기능:
- 수입/지출 기록하기
- 금액, 내용, 카테고리 입력
- 목록으로 보여주기
- 삭제 기능

디자인:
- 깔끔한 카드 형태
- 수입은 파란색, 지출은 빨간색

TypeScript + Tailwind CSS 사용
```

**차이점이 보이시나요?**

| 나쁜 프롬프트 | 좋은 프롬프트 |
|-------------|-------------|
| 뭘 원하는지 불명확 | 원하는 것이 명확함 |
| AI가 추측해야 함 | AI가 바로 이해함 |
| 결과가 엉뚱할 수 있음 | 원하는 결과가 나옴 |

---

### 좋은 프롬프트 5가지 원칙

#### 1. 구체적으로 말하기

```
❌ "버튼 만들어"
✅ "파란색 로그인 버튼 만들어줘. 클릭하면 /login 페이지로 이동하게."
```

#### 2. 기술 스택 알려주기

```
❌ "페이지 만들어"
✅ "TypeScript, Tailwind CSS 사용해서 페이지 만들어줘."
```

#### 3. 현재 상황 설명하기

```
❌ "에러 고쳐줘"
✅ "로그인 페이지 만들고 있는데, 버튼 클릭하면 에러가 나. 여기 에러 메시지야: [에러 내용]"
```

#### 4. 원하는 결과 예시 주기

```
❌ "카드 만들어"
✅ "당근마켓처럼 상품 이미지, 제목, 가격이 보이는 카드 만들어줘."
```

#### 5. 한 번에 하나씩 요청하기

```
❌ "회원가입, 로그인, 상품등록, 댓글 기능 만들어줘"
✅ "먼저 회원가입 기능만 만들어줘."
   (완료 후) "이제 로그인 기능 만들어줘."
```

## 2.2 AI 응답 구분하기 ⭐

**이 부분이 정말 중요합니다!**

AI가 응답을 주면, 그게 무엇인지 구분해야 합니다.
구분 못 하면 뭘 해야 할지 모르게 됩니다.

### AI 응답의 4가지 종류

| 종류 | 특징 | 해야 할 것 |
|------|------|-----------|
| 📄 **코드** | 파일에 넣을 내용 | Apply 버튼으로 적용 |
| 💻 **터미널 명령어** | 직접 입력할 명령 | 터미널에 타이핑 |
| 📖 **설명** | 이해를 돕는 텍스트 | 읽기 (안 해도 됨) |
| 🌐 **외부 작업** | 다른 사이트에서 할 것 | 해당 사이트에서 수행 |

---

### 📄 코드일 때

AI가 코드를 줄 때는 이런 특징이 있습니다:

- "app/page.tsx 파일을 수정해줘"
- "다음 코드를 넣어주세요"
- 파일명이 언급됨 (`.tsx`, `.ts`, `.css` 등)

**예시:**

```
app/page.tsx 파일을 다음과 같이 수정하세요:
```

```tsx
export default function Home() {
  return (
    <div>
      <h1>안녕하세요!</h1>
    </div>
  );
}
```

**→ Apply 버튼을 눌러서 적용합니다!**

<!-- 스크린샷: Apply 버튼 -->

---

### 💻 터미널 명령어일 때

AI가 터미널 명령어를 줄 때는 이런 특징이 있습니다:

- "터미널에서 실행하세요"
- `npm`, `npx`, `cd` 등으로 시작
- 코드 블록 안에 짧은 명령어

**예시:**

```
터미널에서 다음 명령어를 실행하세요:
```

```bash
npm install @supabase/supabase-js
```

**→ 터미널에 직접 타이핑하고 Enter!**

<!-- 스크린샷: 터미널에 명령어 입력 -->

> ⚠️ **주의**: 코드처럼 생겼어도 `npm`, `npx`로 시작하면 터미널 명령어입니다!

---

### 📖 설명일 때

AI가 설명을 줄 때는 이런 특징이 있습니다:

- "~란 ~입니다"
- "이 코드는 ~하는 역할입니다"
- 개념 설명, 이유 설명

**예시:**

```
useState는 React에서 상태를 관리하는 훅입니다.
상태가 변경되면 컴포넌트가 다시 렌더링됩니다.
```

**→ 읽고 이해하면 됩니다. (지금 이해 안 해도 괜찮아요!)**

---

### 🌐 외부 작업일 때

AI가 다른 곳에서 할 작업을 알려줄 때:

- "Supabase 대시보드에서..."
- "GitHub에서..."
- "브라우저에서..."
- "Vercel에서..."

**예시:**

```
Supabase 대시보드에서 새 프로젝트를 만드세요:
1. supabase.com 접속
2. New Project 클릭
3. 프로젝트 이름 입력
```

**→ 해당 웹사이트에서 직접 수행합니다!**

---

### 실제 예시: AI 응답 읽기

AI가 이렇게 응답했다고 가정해봅시다:

---

**AI 응답:**

먼저 패키지를 설치하세요:

```bash
npm install @supabase/supabase-js
```

그 다음 `lib/supabase.ts` 파일을 만들어주세요:

```typescript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!
const supabaseKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!

export const supabase = createClient(supabaseUrl, supabaseKey)
```

Supabase는 PostgreSQL 기반의 오픈소스 백엔드 서비스입니다.
데이터베이스, 인증, 스토리지 등을 쉽게 사용할 수 있습니다.

---

**이걸 어떻게 구분할까요?**

| 부분 | 종류 | 해야 할 것 |
|------|------|-----------|
| `npm install ...` | 💻 터미널 명령어 | 터미널에 입력 |
| `import { createClient }...` | 📄 코드 | Apply로 적용 |
| "Supabase는 PostgreSQL..." | 📖 설명 | 읽기 (선택) |

## 2.3 AI 응답 적용하는 법

### 코드 적용하기 (Apply)

AI가 코드를 주면:

1. **Apply 버튼 클릭**
   <!-- 스크린샷: Apply 버튼 위치 -->

2. **변경 내용 확인**
   - 🟢 초록색 = 추가되는 코드
   - 🔴 빨간색 = 삭제되는 코드
   <!-- 스크린샷: diff 화면 -->

3. **Accept 클릭** (적용하려면)
   또는 **Reject 클릭** (취소하려면)
   <!-- 스크린샷: Accept/Reject 버튼 -->

4. **저장하기**
   - Windows: `Ctrl + S`
   - Mac: `Cmd + S`

---

### 여러 파일이 수정될 때

AI가 한 번에 여러 파일을 수정하라고 할 수 있습니다.

<!-- 스크린샷: 여러 파일 수정 -->

**이럴 때는:**
1. 파일별로 하나씩 확인
2. 순서대로 Apply
3. 모두 적용 후 저장

---

### 터미널 명령어 실행하기

1. **터미널 열기**
   - 메뉴: `View` → `Terminal`
   - 단축키: `` Ctrl + ` `` (Windows) / `` Cmd + ` `` (Mac)

2. **명령어 입력**
   - 직접 타이핑하거나
   - 복사 후 붙여넣기

3. **Enter 누르기**

4. **결과 확인**
   - 에러 없이 완료되면 성공!

<!-- 스크린샷: 터미널 명령어 실행 -->

## 2.4 에러가 났을 때 🚨

### 당황하지 마세요!

> **에러는 정상입니다.**
> **AI도 실수합니다.**
> **에러 메시지는 힌트입니다!**

에러가 났다고 해서 뭔가 잘못된 게 아닙니다.
에러 메시지를 읽고 해결하면 됩니다.

---

### 에러의 종류

#### 1. 빨간 밑줄 (에디터에서)

코드에 빨간 밑줄이 보이면 문제가 있다는 뜻입니다.

<!-- 스크린샷: 빨간 밑줄 예시 -->

**해결법:** 밑줄에 마우스를 올리면 에러 메시지가 나옵니다.

---

#### 2. 터미널 에러 (빨간 글씨)

명령어 실행 후 빨간 글씨가 나오면 에러입니다.

<!-- 스크린샷: 터미널 에러 예시 -->

**예시:**
```
Error: Cannot find module '@supabase/supabase-js'
```

---

#### 3. 브라우저 에러

웹페이지가 제대로 안 나오거나 에러 화면이 보일 때.

<!-- 스크린샷: 브라우저 에러 예시 -->

---

### 에러 해결 방법 (중요!)

#### Step 1: 에러 메시지 복사

빨간 글씨 전체를 선택해서 복사합니다.
- Windows: `Ctrl + C`
- Mac: `Cmd + C`

#### Step 2: AI에게 붙여넣기

커서의 Chat 기능을 열고, 이렇게 질문합니다:

```
이 에러가 나는데 해결해줘:

[여기에 에러 메시지 붙여넣기]
```

#### Step 3: AI가 알려주는 대로 수정

AI가 해결 방법을 알려주면, 그대로 따라합니다.

#### Step 4: 다시 실행해서 확인

수정 후 다시 실행해서 에러가 해결됐는지 확인합니다.

---

### 에러 해결 예시

**상황:** `npm run dev` 했는데 에러 발생

**에러 메시지:**
```
Error: Cannot find module '@supabase/supabase-js'
```

**AI에게 질문:**
```
이 에러가 나는데 해결해줘:
Error: Cannot find module '@supabase/supabase-js'
```

**AI 응답:**
```
패키지가 설치되지 않았네요.
터미널에서 다음 명령어를 실행하세요:

npm install @supabase/supabase-js
```

**해결!** 🎉

---

### 그래도 안 되면?

1. **더 자세히 설명하기**
   ```
   위에 알려준 대로 했는데 여전히 안 돼.
   지금 상황은 이래:
   [현재 상황 설명]
   ```

2. **코드 전체를 보여주며 질문**
   ```
   이 파일 전체 코드야. 뭐가 문제인지 봐줘:
   [코드 전체]
   ```

3. **처음부터 다시 요청**
   ```
   다시 처음부터 해볼게.
   [원래 요청 다시]
   ```

4. **구글 검색**
   에러 메시지를 그대로 검색하면 해결책이 나오기도 합니다.

## 2.5 되돌리기

잘못 적용했을 때 되돌리는 방법입니다.

### 실행 취소 (Undo)

가장 간단한 방법:
- Windows: `Ctrl + Z` (여러 번 가능)
- Mac: `Cmd + Z` (여러 번 가능)

### Reject 버튼

Apply 하기 전이라면 Reject 버튼을 눌러 취소할 수 있습니다.

<!-- 스크린샷: Reject 버튼 -->

### 저장 안 하고 닫기

파일을 저장하지 않았다면:
1. 파일 탭의 X 버튼 클릭
2. "저장하지 않음" 선택
3. 파일 다시 열기

## 2.6 핵심 정리

```
✅ 좋은 프롬프트 = 구체적 + 기술스택 + 상황설명 + 예시 + 하나씩
✅ AI 응답 구분하기 = 코드 / 터미널 / 설명 / 외부작업
✅ 코드 → Apply 버튼으로 적용
✅ 터미널 → 직접 타이핑
✅ 에러 → 당황하지 말고 AI에게 물어보기
✅ 되돌리기 → Ctrl+Z / Reject
```
