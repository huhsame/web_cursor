# Chapter 5. 세상에 공개하기

지금까지 만든 가계부는 내 컴퓨터에서만 볼 수 있습니다.
이번 챕터에서 **인터넷에 공개**해서 누구나 볼 수 있게 만들어봅니다!

---

## 5.1 배포란?

### 지금 상황

```
내 컴퓨터에서만 볼 수 있음
localhost:3000 → 나만 접속 가능
```

### 배포 후

```
전 세계 누구나 볼 수 있음
https://my-budget-app.vercel.app → 누구나 접속 가능!
```

### 배포 = 인터넷에 공개

> 내 컴퓨터가 아닌 **서버**에 코드를 올려서
> 누구나 접속할 수 있게 하는 것입니다.

---

## 5.2 GitHub이 뭔가요?

### 쉽게 말하면

> **코드 저장소 (클라우드)**입니다.
>
> 구글 드라이브가 문서를 저장하듯,
> GitHub은 코드를 저장합니다.

### 왜 필요한가요?

1. **코드 백업** - 컴퓨터 고장나도 코드 안전
2. **배포에 필요** - Vercel이 GitHub에서 코드를 가져감
3. **협업** - 여러 사람이 함께 작업 가능
4. **포트폴리오** - 내가 만든 것을 보여줄 수 있음

## 5.6 Vercel로 배포하기

### Vercel이 뭔가요?

> **웹사이트를 인터넷에 공개해주는 서비스**입니다.
>
> GitHub에 올린 코드를 가져와서
> 전 세계 어디서나 접속 가능하게 만들어줍니다.

### 무료 플랜

- 개인 프로젝트 무료
- 월 100GB 대역폭
- 충분합니다!

---

### Step 1: Vercel 가입

1. **[vercel.com](https://vercel.com)** 접속
2. **Sign Up** 클릭
3. **Continue with GitHub** 클릭 (GitHub 계정으로 가입)

<!-- 스크린샷: Vercel 가입 -->

### Step 2: 프로젝트 가져오기

1. **Add New...** 또는 **New Project** 클릭
2. **Import Git Repository** 섹션에서
3. `my-budget-app` 저장소 찾기
4. **Import** 클릭

<!-- 스크린샷: 프로젝트 Import -->

### Step 3: 환경변수 설정 (중요!)

Supabase 연결을 위해 환경변수를 설정해야 합니다.

1. **Environment Variables** 섹션 찾기
2. 다음 두 개를 추가:

| Name | Value |
|------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | (Supabase URL) |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | (Supabase Key) |

<!-- 스크린샷: 환경변수 설정 -->

> ⚠️ `.env.local`에 있는 값을 그대로 넣으세요!

### Step 4: 배포하기

**Deploy** 버튼 클릭!

<!-- 스크린샷: Deploy 버튼 -->

배포 진행 상황이 보입니다. 1~2분 기다리세요.

### Step 5: 완료! 🎉

배포가 완료되면 URL이 나타납니다!

```
https://my-budget-app-xxxxx.vercel.app
```

<!-- 스크린샷: 배포 완료 화면 -->

**이 URL을 클릭하면 내 가계부가 열립니다!**

## 5.8 문제가 생겼다면?

### 배포는 됐는데 사이트가 안 열려요

1. Vercel 대시보드에서 **Deployments** 확인
2. 빨간색 에러가 있으면 클릭해서 로그 확인
3. 에러 메시지를 AI에게 질문

### 사이트는 열리는데 데이터가 안 돼요

1. Vercel 환경변수 확인
   - `NEXT_PUBLIC_SUPABASE_URL` 있나요?
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` 있나요?
2. 값이 올바른지 확인 (Supabase 대시보드와 비교)

### 다시 배포하고 싶어요

코드를 수정하고 GitHub에 다시 올리면(Push)
Vercel이 자동으로 다시 배포합니다!
