## 10.1 상품 목록 보기 기능 만들기

### 무엇을 만드나요?

> 메인 페이지에 상품 목록을 카드 형태로 보여줍니다.
> Supabase에 저장된 상품 데이터를 가져와서 표시합니다.
>
이미 메인페이지 상품목록은 구현해두었으니, 더미데이터에 사용자를 넣어달라고 할게요.

### Cursor에게 요청하기

커서 Chat에 이렇게 입력하세요:

```
디비에 저장되어있는 더미데이터에 현재 사용자 정보를 가지고 임의로 배정해줘
```

<!-- 스크린샷: Cursor에 요청 -->

### AI 응답 따라하기

AI가 여러 가지를 알려줄 겁니다:

1. **SQL 실행** (products 테이블 생성)
   - Supabase 대시보드 → SQL Editor
   - Cursor가 만든 SQL 복사해서 붙여넣기
   - Run 버튼 클릭

2. **코드 적용**
   - **Apply** 버튼으로 코드 적용
   - app/page.tsx가 수정됨

3. **파일 저장**

### 무엇이 만들어졌나요?

- ✅ **products 테이블** (Supabase)
  - 상품 정보를 저장하는 곳
- ✅ **app/page.tsx** (메인 페이지)
  - Supabase에서 데이터 가져오기
  - 상품 카드로 표시

### 테스트하기

1. **Supabase Table Editor**에서 테스트 데이터 추가
   - 왼쪽 메뉴 → Table Editor → products
   - Insert Row 클릭
   - 테스트 데이터 입력:
     ```
     title: 아이폰 14
     price: 800000
     description: 깨끗한 상태입니다
     image_url: https://picsum.photos/400/300
     ```
   - Save 클릭

2. **브라우저에서 확인**
   - localhost:3000 접속
   - 방금 추가한 상품이 보이면 성공! 🎉

<!-- 스크린샷: 상품 목록 화면 -->

### 문제가 생겼다면?

**"데이터가 안 불러와져요"**
- .env.local 파일이 있나요?
- 개발 서버를 재시작했나요? (Ctrl+C 후 npm run dev)

**"테이블을 만들 수 없어요"**
- SQL Editor에서 에러 메시지 확인
- Cursor에게 에러 메시지 복사해서 붙여넣기

## 10.2 상품 상세 보기 기능 만들기

### 무엇을 만드나요?

> 상품 카드를 클릭하면 상세 페이지로 이동합니다.
> 큰 이미지와 자세한 정보를 볼 수 있습니다.

### Cursor에게 요청하기

```
상품 카드를 클릭하면 상세 페이지로 이동하게 해줘.
(app/products/[id]/page.tsx)

보여줄 것:
- 큰 이미지
- 제목, 가격, 설명
- 등록 시간
- 판매자 닉네임 (profiles 테이블과 JOIN해서 가져오기)
- 뒤로가기 버튼

참고:
- profiles 테이블은 이미 Chapter 9에서 만들었어.
- products 테이블의 user_id와 profiles 테이블의 id를 JOIN해서
  판매자 닉네임을 가져오면 돼.
```

### AI 응답 따라하기

1. **코드 적용**
   - app/products/[id]/page.tsx 생성
   - AI가 자동으로 JOIN 쿼리 작성해줌

2. **파일 저장**

### 무엇이 만들어졌나요?

- ✅ **상품 상세 페이지** (app/products/[id]/page.tsx)
  - products와 profiles를 JOIN해서 판매자 정보 표시

### 테스트하기

1. **메인 페이지에서 상품 카드 클릭**
2. 상세 페이지로 이동하는지 확인
3. 상품 정보가 제대로 나오는지 확인

<!-- 스크린샷: 상품 상세 화면 -->

### 문제가 생겼다면?

**"판매자 정보가 안 나와요"**
- Supabase Table Editor에서 profiles 테이블 확인
- 회원가입을 다시 해보세요 (새 계정으로)

## 10.3 상품 등록 기능 만들기

> **중요: 여기서부터 Chapter 9의 로그인 기능을 활용합니다!**

### 무엇을 만드나요?

> 로그인한 사용자가 상품을 등록할 수 있습니다.
> 로그인 안 했으면 로그인 페이지로 보냅니다.

### Cursor에게 요청하기

```
로그인한 사용자가 상품을 등록할 수 있는 기능을 만들어줘.
(app/products/new/page.tsx)

입력 받을 것:
- 제목 (필수)
- 가격 (필수, 숫자만)
- 설명 (선택, 여러 줄)
- 이미지 URL (선택)

기능:
- 로그인 안 했으면 로그인 페이지로 보내기
- 등록한 사람의 정보 자동으로 저장 (user_id)
- 등록 완료하면 상품 상세 페이지로 이동
- 저장 중일 때 버튼 비활성화

Chapter 9에서 만든 AuthContext 사용해줘.

그리고 헤더에 "상품 등록" 버튼도 추가해줘.
```

### AI 응답 따라하기

1. **코드 적용**
   - app/products/new/page.tsx 생성
   - app/components/Header.tsx 수정 (상품 등록 버튼 추가)

2. **파일 저장**

### 무엇이 만들어졌나요?

- ✅ **상품 등록 페이지** (app/products/new/page.tsx)
- ✅ **로그인 체크** (AuthContext 사용)
- ✅ **user_id 자동 입력** (로그인한 사용자)
- ✅ **헤더에 등록 버튼**

### 테스트하기

1. **로그아웃 상태**에서 헤더의 "상품 등록" 클릭
   - 로그인 페이지로 리다이렉트 되는지 확인

2. **로그인** 후 상품 등록
   - 제목: 맥북 프로
   - 가격: 1500000
   - 설명: 거의 새 제품입니다
   - 등록 클릭

3. **Supabase Table Editor**에서 확인
   - products 테이블 열기
   - user_id가 채워져 있는지 확인
   - 내가 로그인한 사용자 ID와 같은지 확인

<!-- 스크린샷: user_id가 채워진 상품 -->

### 문제가 생겼다면?

**"user_id가 비어있어요"**
- 로그인 상태에서 등록했나요?
- AuthContext가 제대로 작동하는지 확인 (브라우저 콘솔)

**"로그인 페이지로 안 보내져요"**
- AuthContext가 app/layout.tsx에서 적용되었나요?

## 10.4 내 상품만 수정/삭제하기

### 무엇을 만드나요?

> 상품 상세 페이지에 수정/삭제 버튼을 추가합니다.
> 단, **본인이 등록한 상품만** 버튼이 보입니다.

### Cursor에게 요청하기

```
상품 상세 페이지에 수정/삭제 기능을 추가해줘.

조건:
- 내가 등록한 상품만 수정/삭제 버튼 보이게
- 다른 사람 상품에는 버튼 숨기기
- 수정 버튼 클릭 → 수정 페이지로 이동
- 삭제 버튼 클릭 → 확인 후 삭제, 메인 페이지로 이동

본인 확인:
- product.user_id와 현재 로그인한 user.id 비교
- 같으면 버튼 표시, 다르면 숨김

수정 페이지 (app/products/[id]/edit/page.tsx)도 만들어줘:
- 기존 데이터 불러와서 폼에 표시
- 수정 후 저장하면 상세 페이지로 이동
- 본인 상품이 아니면 접근 못하게
```

### AI 응답 따라하기

1. **코드 적용**
   - app/products/[id]/page.tsx 수정 (수정/삭제 버튼)
   - app/products/[id]/edit/page.tsx 생성 (수정 페이지)

2. **파일 저장**

### 무엇이 만들어졌나요?

- ✅ **본인 확인 로직** (user_id 비교)
- ✅ **수정/삭제 버튼** (본인만 보임)
- ✅ **상품 수정 페이지**
- ✅ **삭제 기능**

### 테스트하기

1. **내가 등록한 상품** 상세 페이지 가기
   - 수정/삭제 버튼이 보이는지 확인

2. **다른 계정으로 로그인**
   - 같은 상품 상세 페이지 가기
   - 수정/삭제 버튼이 안 보이는지 확인

3. **수정 기능 테스트**
   - 수정 버튼 클릭
   - 제목/가격 변경
   - 저장 → 상세 페이지에서 변경 확인

4. **삭제 기능 테스트**
   - 삭제 버튼 클릭
   - 확인 → 메인 페이지로 이동
   - 목록에서 사라졌는지 확인

<!-- 스크린샷: 본인 상품 (버튼 보임) -->
<!-- 스크린샷: 다른 사람 상품 (버튼 안 보임) -->

### 문제가 생겼다면?

**"버튼이 항상 보여요"**
- user_id 비교 로직 확인
- 브라우저 콘솔에서 user.id와 product.user_id 출력해보기

**"다른 사람 상품을 수정할 수 있어요"**
- 수정 페이지에서도 본인 확인하는지 체크
- Cursor에게 보안 체크 추가 요청

## 10.5 댓글 기능 만들기

### 무엇을 만드나요?

> 상품 상세 페이지에 댓글을 달 수 있습니다.
> 로그인한 사용자만 댓글을 작성할 수 있습니다.

### Cursor에게 요청하기

```
상품 상세 페이지에 댓글 기능을 추가해줘.

필요한 것:
- 로그인한 사용자만 댓글 작성 가능
- 댓글 작성자 닉네임 표시
- 내가 쓴 댓글만 삭제 가능
- 최신순 정렬
- 작성 시간 표시

comments 테이블을 만들어줘:
- id (자동 생성)
- content (댓글 내용)
- product_id (어느 상품의 댓글인지)
- user_id (작성한 사용자)
- created_at (작성 시간)

상품 상세 페이지에 댓글 섹션 추가:
- 댓글 목록
- 댓글 작성 폼 (로그인 시에만 보임)
```

### AI 응답 따라하기

1. **SQL 실행** (comments 테이블 생성)
   - Supabase SQL Editor에서 실행

2. **코드 적용**
   - app/products/[id]/page.tsx 수정 (댓글 섹션 추가)

3. **파일 저장**

### 무엇이 만들어졌나요?

- ✅ **comments 테이블** (댓글 저장)
- ✅ **댓글 목록 표시**
- ✅ **댓글 작성 폼**
- ✅ **댓글 삭제 기능** (본인만)

### 테스트하기

1. **로그인 상태**에서 상품 상세 페이지 가기
2. **댓글 작성**
   - 댓글 입력
   - 작성 버튼 클릭
   - 바로 아래에 표시되는지 확인

3. **다른 계정으로 로그인**
   - 같은 상품에 댓글 작성
   - 이전 댓글은 삭제 버튼 안 보이는지 확인
   - 내 댓글은 삭제 버튼 보이는지 확인

4. **Supabase Table Editor**에서 확인
   - comments 테이블 열기
   - user_id, product_id가 제대로 들어갔는지 확인

## 핵심 정리

```
✅ 10.1 상품 목록 - Supabase 데이터 조회
✅ 10.2 상품 상세 - 단일 데이터 조회, 판매자 정보 표시
✅ 10.3 상품 등록 - 로그인 체크, user_id 자동 입력
✅ 10.4 수정/삭제 - 본인 확인 (user_id 비교)
✅ 10.5 댓글 - 로그인 체크, 본인만 삭제

핵심 개념:
- Supabase에서 데이터 가져오기 (SELECT)
- Supabase에 데이터 추가하기 (INSERT)
- Supabase 데이터 수정하기 (UPDATE)
- Supabase 데이터 삭제하기 (DELETE)
- AuthContext로 로그인 확인
- user_id로 본인 확인
- 테이블 조인 (profiles)
```

**중요한 흐름:**
