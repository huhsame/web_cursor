## 13.1 배포 전 점검

### 기능 체크리스트

배포 전에 모든 기능이 잘 동작하는지 확인하세요!

- [ ] 회원가입이 되나요?
- [ ] 로그인/로그아웃이 되나요?
- [ ] 상품 등록이 되나요?
- [ ] 상품 목록이 보이나요?
- [ ] 상품 상세 페이지가 보이나요?
- [ ] 상품 수정이 되나요? (본인 것만)
- [ ] 상품 삭제가 되나요? (본인 것만)
- [ ] 댓글 작성/삭제가 되나요?
- [ ] 이미지 업로드가 되나요?
- [ ] 검색이 되나요?

### 에러 점검

브라우저 개발자 도구(F12)에서 콘솔 에러가 없는지 확인하세요.

---

## 13.3 Vercel 배포

### Step 1: Vercel 접속

1. **[vercel.com](https://vercel.com)** 접속
2. GitHub 계정으로 로그인

### Step 2: 프로젝트 가져오기

1. **Add New** → **Project** 클릭
2. GitHub 저장소 목록에서 `goguma-market` 찾기
3. **Import** 클릭

<!-- 스크린샷: 프로젝트 Import -->

### Step 3: 환경변수 설정 ⚠️ 중요!

**Environment Variables** 섹션에서 추가:

| Name | Value |
|------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | (Supabase URL) |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | (Supabase Key) |

<!-- 스크린샷: 환경변수 설정 -->

> ⚠️ `.env.local` 에 있는 값을 그대로 넣으세요!
> 환경변수 없으면 DB 연결이 안 됩니다!

### Step 4: 배포하기

**Deploy** 버튼 클릭!

배포가 진행됩니다. 1~2분 기다리세요.

<!-- 스크린샷: 배포 진행 중 -->

### Step 5: 완료! 🎉

배포가 완료되면 URL이 나타납니다!

```
https://goguma-market-xxxxx.vercel.app
```

**이 URL을 클릭하면 고구마마켓이 열립니다!**

<!-- 스크린샷: 배포 완료 -->

## 13.4 배포된 사이트 테스트

### 테스트 항목

1. **회원가입** - 새 계정으로 가입되나요?
2. **로그인** - 로그인이 되나요?
3. **상품 등록** - 이미지 포함해서 등록되나요?
4. **목록** - 등록한 상품이 보이나요?
5. **댓글** - 댓글이 작성되나요?

### 문제가 있다면?

1. Vercel 대시보드 → **Deployments** 탭
2. 최근 배포 클릭
3. **Logs** 확인

에러 메시지를 AI에게 질문:
```
Vercel 배포 후 이 에러가 나는데 해결해줘:
[에러 메시지]
```

## 13.5 도메인 연결 (선택)

### 커스텀 도메인이란?

```
기본: https://goguma-market-xxxxx.vercel.app
커스텀: https://goguma-market.com
```

### 연결 방법

1. Vercel 프로젝트 → **Settings** → **Domains**
2. 도메인 입력 후 **Add**
3. DNS 설정 안내에 따라 설정

> 💡 도메인은 별도로 구매해야 합니다!
> (가비아, 카페24 등)
