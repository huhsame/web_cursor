## 11.1 이미지 업로드 기능

### Supabase Storage 설정

#### Step 1: 버킷 만들기

1. Supabase 대시보드 → **Storage** 메뉴
2. **New bucket** 클릭
3. 설정:
   - **Name**: `product-images`
   - **Public bucket**: ON (체크)
4. **Create bucket** 클릭

<!-- 스크린샷: 버킷 생성 -->

#### Step 2: 정책 설정

1. 생성된 `product-images` 버킷 클릭
2. **Policies** 탭 클릭
3. **New policy** 클릭
4. **For full customization** 선택

아래 정책들을 추가:

**업로드 정책:**
```sql
CREATE POLICY "로그인한 사용자만 업로드 가능"
ON storage.objects FOR INSERT
WITH CHECK (
  bucket_id = 'product-images'
  AND auth.role() = 'authenticated'
);
```

**읽기 정책:**
```sql
CREATE POLICY "누구나 이미지 조회 가능"
ON storage.objects FOR SELECT
USING (bucket_id = 'product-images');
```

### 상품 등록 페이지에 이미지 업로드 추가

#### AI에게 요청하기

```
상품 등록 페이지에 이미지 업로드 기능을 추가해줘.

- 파일 선택 input 추가
- 이미지 선택하면 미리보기 표시
- 폼 제출 시 이미지를 Supabase Storage에 업로드
- 업로드된 이미지 URL을 products 테이블에 저장
- 이미지 없이도 등록 가능

Supabase Storage 사용
버킷 이름: product-images
TypeScript + Tailwind
```

### 적용 및 테스트

1. Apply → Accept → 저장
2. 상품 등록 페이지에서 이미지 선택
3. 미리보기 확인
4. 상품 등록 후 상세 페이지에서 이미지 표시 확인

## 11.2 검색 기능 만들기

### 검색창 추가

#### AI에게 요청하기

```
메인 페이지에 검색 기능을 추가해줘.

검색창:
- 헤더 아래 또는 상품 목록 위에 배치
- 검색어 입력 + 검색 버튼
- Enter 키로도 검색 가능

검색 기능:
- 상품 제목에서 검색어 포함된 것 찾기
- Supabase의 ilike 사용 (대소문자 구분 없음)
- 검색 결과가 없으면 "검색 결과가 없습니다" 표시
- 검색어 지우면 전체 목록 표시

TypeScript + Tailwind
```

### 적용 및 테스트

1. Apply → Accept → 저장
2. 검색창에 키워드 입력
3. 검색 결과 확인
4. 없는 키워드로 검색 시 메시지 확인

## 11.4 무한 스크롤 (선택)

상품이 많아지면 페이지네이션이나 무한 스크롤이 필요합니다.

### AI에게 요청하기

```
메인 페이지에 무한 스크롤을 구현해줘.

- 처음에 12개만 로드
- 스크롤이 하단에 도달하면 다음 12개 로드
- 더 이상 상품이 없으면 "더 이상 상품이 없습니다" 표시
- 로딩 중 표시

Intersection Observer API 사용
TypeScript + Tailwind
```
