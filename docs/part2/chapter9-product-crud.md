## 9.1 상품 목록 페이지 (실제 DB 연결)

7장에서 만든 메인 페이지는 **임시 데이터**를 사용했습니다.
이제 **Supabase에서 실제 데이터**를 가져오도록 수정합니다.

### AI에게 요청하기

```
메인 페이지(app/page.tsx)를 수정해서
Supabase에서 상품 목록을 가져오게 해줘.

- products 테이블에서 데이터 조회
- 최신순 정렬 (created_at 내림차순)
- 로딩 중 표시
- 에러 시 메시지 표시
- ProductCard 컴포넌트 사용

lib/supabase.ts의 supabase 클라이언트 사용
TypeScript + Tailwind
```

### 적용하기

1. Apply → Accept
2. 저장

### 테스트하기

1. 브라우저에서 `localhost:3000` 확인
2. Supabase Table Editor에서 상품 추가
3. 브라우저 새로고침 → 상품이 보이면 성공!

## 9.2 상품 상세 페이지

### 동적 라우팅이란?

> **URL에 따라 다른 내용을 보여주는 것**입니다.

```
/products/1  → 1번 상품 보여줌
/products/2  → 2번 상품 보여줌
/products/99 → 99번 상품 보여줌
```

Next.js에서는 폴더명에 `[id]` 처럼 대괄호를 쓰면 동적 라우팅이 됩니다.

```
app/products/[id]/page.tsx
→ /products/아무숫자 에 대응
```

### AI에게 요청하기

```
상품 상세 페이지를 만들어줘.
(app/products/[id]/page.tsx)

표시할 정보:
- 상품 이미지 (크게)
- 제목
- 가격 (₩ 표시, 콤마)
- 판매 상태 (판매중/예약중/판매완료)
- 등록 시간
- 상품 설명
- 판매자 정보 (닉네임)

기능:
- Supabase에서 해당 상품 조회
- 없는 상품이면 "상품을 찾을 수 없습니다" 표시
- 뒤로가기 버튼

TypeScript + Tailwind
모바일 반응형
```

### 적용하기

1. Apply → Accept
2. 저장

### 테스트하기

1. 메인 페이지에서 상품 카드 클릭
2. 상세 페이지로 이동하는지 확인
3. 상품 정보가 제대로 나오는지 확인

## 9.3 상품 등록 페이지

### AI에게 요청하기

```
상품 등록 페이지를 만들어줘.
(app/products/new/page.tsx)

입력 필드:
- 제목 (필수)
- 가격 (필수, 숫자만)
- 설명 (선택, 여러 줄)
- 이미지 URL (선택)

기능:
- 폼 제출시 Supabase products 테이블에 저장
- 저장 성공하면 상품 상세 페이지로 이동
- 저장 중 버튼 비활성화
- 에러 시 메시지 표시

'use client' 사용
TypeScript + Tailwind
깔끔한 폼 디자인
```

### 적용하기

1. Apply → Accept
2. 저장

### 헤더에 등록 버튼 추가하기

```
app/layout.tsx의 헤더에
"상품 등록" 버튼을 추가해줘.
클릭하면 /products/new 로 이동.
```

### 테스트하기

1. 헤더의 "상품 등록" 버튼 클릭
2. 정보 입력 후 등록
3. 상세 페이지로 이동하는지 확인
4. 메인 페이지에서 새 상품이 보이는지 확인

## 9.4 상품 수정 페이지

### AI에게 요청하기

```
상품 수정 페이지를 만들어줘.
(app/products/[id]/edit/page.tsx)

- 기존 상품 정보를 폼에 미리 채워넣기
- 제목, 가격, 설명, 이미지URL, 상태 수정 가능
- 상태: 판매중, 예약중, 판매완료 선택
- 저장하면 Supabase 업데이트
- 저장 성공하면 상세 페이지로 이동

'use client' 사용
TypeScript + Tailwind
```

### 상세 페이지에 수정 버튼 추가

```
상품 상세 페이지에 "수정" 버튼을 추가해줘.
클릭하면 /products/[id]/edit 로 이동.
```

1. Apply → Accept → 저장
2. 상세 페이지에서 수정 버튼 클릭
3. 정보 수정 후 저장
4. 변경사항이 반영되는지 확인

## 9.6 CRUD 완성! 🎉

### 지금까지 만든 것

| 기능 | 페이지 | 설명 |
|------|--------|------|
| **C**reate | /products/new | 상품 등록 |
| **R**ead | / , /products/[id] | 목록, 상세 조회 |
| **U**pdate | /products/[id]/edit | 상품 수정 |
| **D**elete | /products/[id] | 상품 삭제 |

### 파일 구조

```
app/
├── page.tsx              # 메인 (상품 목록)
├── layout.tsx            # 공통 레이아웃
├── products/
│   ├── new/
│   │   └── page.tsx      # 상품 등록
│   └── [id]/
│       ├── page.tsx      # 상품 상세
│       └── edit/
│           └── page.tsx  # 상품 수정
└── components/
    └── ProductCard.tsx   # 상품 카드 컴포넌트
```

## 9.7 남은 문제점

### 1. 로그인 없이 누구나 등록/수정/삭제 가능

```
→ 다음 챕터에서 로그인 기능 추가!
```

### 2. user_id가 없어서 판매자 정보 없음

```
→ 로그인 후 자동으로 user_id 저장되게 수정
```

### 3. 본인 상품만 수정/삭제 버튼 보여야 함

```
→ 로그인한 사용자와 상품 등록자 비교
```
