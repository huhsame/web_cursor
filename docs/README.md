# 커서(Cursor)로 Next.js 앱 개발하기

## 강의 개요

> **"AI와 함께라면, 누구나 개발자가 될 수 있습니다"**

이 강의는 프로그래밍 경험이 없는 분들도 AI 코딩 도구인 **커서(Cursor)**를 활용해
실제 동작하는 웹 서비스를 만들어보는 3일 과정입니다.

---

## 수강 대상

- 코딩을 한 번도 해본 적 없는 완전 초보자
- 웹 개발에 관심은 있지만 어디서 시작해야 할지 모르는 분
- AI로 개발하는 것이 궁금한 분
- 나만의 웹 서비스를 만들어보고 싶은 분

## 완성하게 될 프로젝트

### 1. 투두앱 (Todo App)
- 할 일 추가, 수정, 삭제, 완료 체크
- 데이터베이스 연동
- 실제 배포까지

### 2. 중고거래 마켓앱
- 회원가입/로그인
- 상품 CRUD (등록, 조회, 수정, 삭제)
- 이미지 업로드
- 댓글 기능
- 검색 기능

---

## 사용 기술 스택

| 기술 | 역할 | 왜 이걸 쓰나요? |
|------|------|----------------|
| **Cursor** | AI 코딩 도구 | 코드를 대신 작성해주는 AI 비서 |
| **Next.js** | 웹 프레임워크 | React 기반, 풀스택 개발 가능 |
| **Supabase** | 백엔드 서비스 | DB, 인증, 스토리지를 쉽게 |
| **Vercel** | 배포 플랫폼 | 클릭 몇 번으로 전세계 배포 |
| **Git/GitHub** | 버전 관리 | 코드 히스토리 관리, 협업 |
