## 사용하는 도구들

| 도구 | 용도 | 비용 |
|------|------|------|
| **Cursor** | AI 코드 편집기 | 무료 (Pro: 월 $20) |
| **Next.js** | 웹 프레임워크 | 무료 |

| **GitHub** | 코드 저장소 | 무료 |

### 무료 플랜 제한 안내

> **Cursor 무료**
> - 월 2,000회 AI 요청 (느린 모델)
> - Pro 플랜: 월 500회 빠른 요청 + 무제한 느린 요청
>
> **Supabase 무료**
> - 프로젝트 2개
> - 500MB 데이터베이스 저장공간
> - 1GB 파일 저장공간
>
> **Vercel 무료**
> - 월 100GB 대역폭
> - 상업적 사용 제한
>
> 💡 **강의 실습에는 무료 플랜으로 충분합니다!**

## 버전 정보

이 강의는 아래 버전 기준으로 작성되었습니다.

| 도구 | 버전 | 확인 방법 |
|------|------|----------|
| Node.js | 20.x LTS | `node --version` |
| npm | 10.x | `npm --version` |
| Next.js | 14.x | `package.json` 확인 |
| Cursor | 최신 버전 | 자동 업데이트됨 |

> ⚠️ **버전이 다르면?**
>
> 화면이나 메뉴가 조금 다를 수 있지만, 핵심 기능과 흐름은 동일합니다.
> 너무 걱정하지 마세요!
