## 1. 왜 AI로 개발하나요?

### 쉬운 설명
> 여러분이 외국에 갔는데 언어를 모른다고 상상해보세요.
> 예전에는 사전 찾고, 문법 공부하고... 힘들었죠.
> 지금은? **번역기 앱** 하나면 됩니다.
>
> 코딩도 마찬가지입니다.
> 예전에는 문법 외우고, 에러 찾고... 힘들었어요.
> 지금은? **AI 코딩 도구** 하나면 됩니다.

### 공식적인 설명
```
AI 코딩 어시스턴트는 대규모 언어 모델(LLM)을 기반으로
자연어 명령을 프로그래밍 코드로 변환하는 도구입니다.
개발자의 생산성을 크게 향상시키며,
프로그래밍 진입 장벽을 낮추는 역할을 합니다.
```

### AI 코딩의 장점

| 장점 | 설명 |
|------|------|
| **진입 장벽 낮춤** | 문법을 다 외우지 않아도 됨 |
| **빠른 프로토타이핑** | 아이디어를 빠르게 구현 |
| **학습 도우미** | 코드 설명을 물어볼 수 있음 |
| **에러 해결** | 에러 메시지 복붙하면 해결책 제시 |

## 2. 커서(Cursor)란?

### 쉬운 설명
> 커서는 **AI 비서가 내장된 코드 편집기**입니다.
>
> "로그인 기능 만들어줘"라고 말하면
> 진짜로 코드를 작성해줍니다.
>
> 마치 옆에 시니어 개발자가 앉아서
> 대신 코딩해주는 느낌이에요.

### 공식적인 설명
```
Cursor는 VS Code를 기반으로 한 AI-native IDE입니다.
Claude, GPT 등 다양한 AI 모델을 통합하여
코드 자동 완성, 코드 생성, 리팩토링,
에러 수정 등의 기능을 제공합니다.
```

### 커서 vs 일반 코드 편집기

| 기능 | 일반 편집기 | 커서 |
|------|------------|------|
| 코드 작성 | 직접 타이핑 | AI가 대신 작성 |
| 에러 수정 | 구글 검색 | AI에게 질문 |
| 코드 이해 | 문서 찾아보기 | AI가 설명해줌 |
| 새 기능 추가 | 처음부터 작성 | "~해줘" 한마디 |

## 3. 커서 설치하기

### Step 1: 다운로드

1. 브라우저에서 [cursor.com](https://cursor.com) 접속
2. **Download** 버튼 클릭
3. 운영체제에 맞는 버전 자동 선택됨

```
Windows: Cursor Setup.exe
Mac: Cursor.dmg
Linux: Cursor.AppImage
```

### Step 2: 설치

**Windows:**
1. 다운로드된 `.exe` 파일 실행
2. "다음" 계속 클릭
3. 설치 완료

**Mac:**
1. 다운로드된 `.dmg` 파일 열기
2. Cursor 아이콘을 Applications 폴더로 드래그
3. 처음 실행 시 "열기" 허용

### Step 3: 초기 설정

1. Cursor 실행
2. **Sign Up** 또는 **Log In** (구글 계정으로 가능)
3. AI 모델 선택 화면에서 **Claude** 선택 권장

```
💡 팁: Claude가 코딩에 특화되어 있어 추천합니다.
     GPT-4도 훌륭하니 취향에 따라 선택하세요.
```

### Step 4: 한글 설정 (선택)

1. `Cmd/Ctrl + Shift + P` 눌러 명령 팔레트 열기
2. "Configure Display Language" 입력
3. "한국어" 선택

## 4. 커서 기본 사용법

### 핵심 단축키 3가지만 기억하세요!

| 단축키 | 기능 | 언제 쓰나요? |
|--------|------|-------------|
| `Cmd/Ctrl + K` | 코드 생성 | 새로운 코드를 만들 때 |
| `Cmd/Ctrl + L` | AI 채팅 | 질문하거나 설명 요청할 때 |
| `Cmd/Ctrl + I` | 인라인 편집 | 기존 코드를 수정할 때 |

### 실습: 첫 AI 대화

1. 커서를 열고 새 파일 생성 (`Cmd/Ctrl + N`)
2. `Cmd/Ctrl + L`로 AI 채팅창 열기
3. 다음과 같이 입력:

```
안녕! 나는 오늘 처음 코딩을 배우는 학생이야.
간단한 "Hello World"를 출력하는 JavaScript 코드를 보여줘.
```

4. AI가 코드를 생성하면 **Apply** 버튼 클릭

**예상 결과:**
```javascript
console.log("Hello World");
```

### 좋은 프롬프트 vs 나쁜 프롬프트

**나쁜 예:**
```
로그인
```

**좋은 예:**
```
이메일과 비밀번호를 입력받는 로그인 폼을 만들어줘.
React 컴포넌트로 만들고,
입력값이 비어있으면 버튼이 비활성화되게 해줘.
```

### 프롬프트 작성 팁

1. **구체적으로**: 무엇을 원하는지 명확하게
2. **맥락 제공**: 어떤 기술을 사용하는지
3. **단계별로**: 복잡한 건 나눠서 요청
4. **예시 포함**: 원하는 결과물 예시 제공
